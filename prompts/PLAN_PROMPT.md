# Plan Mode Prompt

Before planning, read `AGENTS.md`, `README.md`, and relevant documents under `docs/`. Inspect the repository, dataset (if present), current Git status, and relevant code/tests.

Do not implement yet.

Return:
1. Your understanding of the goal and acceptance criteria.
2. What currently exists and what is missing.
3. A small, bounded implementation plan in ordered steps.
4. Exact files you expect to create/change and why.
5. Security/privacy risks and contract constraints.
6. Tests to add/run, including expected outcomes.
7. Dependencies required (if any), with justification.
8. Documentation that will be created/updated.
9. Any assumptions or questions that block implementation.

Keep scope limited to this milestone. Do not commit, push, merge, or perform destructive operations.
