# RAG Knowledge Base

Individual development repository for the RAG Knowledge Base track
of the Multi-Tenant B2B Customer Support AI project.

## Project Goals

- Document ingestion and preprocessing
- Metadata-preserving chunking
- Embedding generation
- Vector retrieval
- Tenant and access-level isolation
- Hybrid retrieval
- Retrieval evaluation
- CLI-first testing
- Optional demonstration UI
